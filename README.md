#  Jharkhand Darshan

Jharkhand Darshan is a simple web project that highlights the cultural heritage and major tourist destinations of Jharkhand through a clean and user-friendly interface.

##  Tech Stack
- HTML
- CSS
- JavaScript

##  Features
- Showcases popular tourist places
- Simple navigation and clean UI
- Beginner-friendly static website
